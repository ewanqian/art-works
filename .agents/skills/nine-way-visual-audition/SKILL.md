# Nine-way Visual Audition / 并行探索，作者选择

This is a **comparison process**, not an instruction to generate nine near-duplicates or nine new projects. Start with one **fixed source scene and one evaluation question**. Preserve source identity, screenshot aspect ratio, framing and rights unless that variable is the subject of the test.

## 1. Choose the axis and keep the control stable

Examples:
- Lighting: 3 physical directions (underlight / side key / top-down) × 3 deliberate accent systems (rim / edge scan / environmental fill).
- Motion: 3 cadence/curve families × 3 intensity levels, all applied to **the same original geometry and audio slice**.
- Geometry: 3 topology/spatial organization families × 3 density/scale relations, preserving actual original mechanism.
- Compositor: 3 highlight/envelope choices × 3 texture/tonal treatments with comparable exposure.

A grid may use two axes, but **label both**. Do not silently change camera, material, sound, lighting and geometry together or comparisons become uninterpretable. Avoid automatic strobe/flash-heavy results; allow a calm/blackout fallback.

## 2. Produce real evidence, not only a prompt grid

For each candidate, provide: ID, exact changed variable, fixed assumptions, a rendered still, and if motion matters a 3–8-second loop under the *same* musical excerpt. Label missing renders `NOT_RENDERED`; do not manufacture imaginary previews or claim a proposal was tested.

Record:
- Artistic effect: what changes in perceived scale, density, attention, motion or emotional character?
- Usability: how it behaves under actual output aspect and during transitions.
- Rejections: why a visually flashy option is weaker than a restrained one.
- Source boundary: licensed model/video/music and any local-only node recipe.

## 3. Select with the artist

Make a 3×3 comparison and nominate **at most two** candidates for artist comparison. This is a *recommendation*, not an accepted work. Save the selected variation's ID, author wording and visible evidence; do not hallucinate a forgotten second choice. Keep the other seven as intentional rejections/alternative studies, not nine production obligations.

## 4. Preserve method rather than screenshots alone

Save in a local/public-safe ledger:
`source_asset_id, test_question, fixed_conditions, changed_parameter_axis, candidate_ids, capture_paths, author_choice, rejection_reason, evidence_tier, rights_status`.

If precise lighting/material values or original commercial assets are involved, store private parameter files locally. A public style card should describe a method and why it works, not expose the author's full proprietary source setup.
